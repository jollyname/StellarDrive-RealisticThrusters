# StellarDrive - RealisticThrusters
Makes thrusters push from where they're mounted, instead of from the ship's center of mass.
Thrusters placed off-center now turn the ship, so thruster placement and balance matter.

> [!IMPORTANT]
> Only thrusters on the main ship are affected. Thrusters on docked ships and sub-ships still push from the center of mass.

## Notes
- Thrusters added by other mods may not be supported and still push from the center of mass.
- Other thruster types added in future game updates may need a mod update.
